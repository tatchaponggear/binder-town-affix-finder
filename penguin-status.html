คำถามที่พบบ่อย

Windows ขึ้น “Windows protected your PC”

เพราะโปรแกรมยังไม่ได้ซื้อใบรับรองเซ็นชื่อ กด More info → Run anyway ครั้งเดียวพอ

Mac ขึ้นว่าเปิดไม่ได้ / ไม่รู้จักผู้พัฒนา
  1. ปิดหน้าต่างแจ้งเตือน
  2. ไปที่ System Settings → Privacy & Security
  3. เลื่อนลงล่าง กด Open Anyway ข้าง “Penguin Status” แล้วยืนยัน (ทำครั้งเดียว)
เปิดโปรแกรมแล้วแต่สถานะไม่ขึ้น

เช็ก Discord → Settings → Activity Privacy → เปิด “Share your detected activities with others” · ปิดโหมด Invisible · ต้องใช้ Discord แบบแอป ไม่ใช่บนเว็บ

โดนแบนไหม / ผิดกฎ Discord ไหม

ไม่ใช่ selfbot ไม่ได้ใช้ token บัญชี ใช้ Rich Presence ช่องทางเดียวกับที่เกมทั่วไปใช้ผ่านแอป Discord ในเครื่อง

เปลี่ยนข้อความหรือปุ่มได้ไหม

ได้ทุกช่อง แก้ระหว่างเปิดอยู่ได้เลย สถานะอัปเดตเองภายใน 15 วินาที ค่าที่ตั้งจะจำไว้ให้ครั้งหน้า
