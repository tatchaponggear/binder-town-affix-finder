สรุปสั้นๆ

ไม่เก็บข้อมูลส่วนตัว PenguinCLI (เดิมชื่อ Penguin Status) เป็นโปรแกรมบนเครื่องที่ตั้งสถานะ Discord และมีโอเวอร์เลย์เวลาบอส โปรแกรมไม่มีบัญชีผู้ใช้ ไม่มีเซิร์ฟเวอร์ของเราเอง ไม่ส่งข้อมูลของคุณมาที่เรา และไม่มีระบบติดตามหรือโฆษณา

โปรแกรมทำงานยังไง

  • โปรแกรมคุยกับแอป Discord ที่เปิดอยู่บนเครื่องของคุณโดยตรง ผ่านช่องทาง Rich Presence (IPC) ของ Discord ข้อมูลส่วนนี้ไม่ผ่านอินเทอร์เน็ตมาที่เรา
  • สิ่งที่ส่งให้ Discord มีแค่ข้อความสถานะที่คุณพิมพ์เอง ลิงก์รูป ปุ่มลิงก์ และเวลาเริ่มเล่น จากนั้น Discord แสดงสถานะนั้นในโปรไฟล์ของคุณตามการตั้งค่าของ Discord
  • โปรแกรมไม่ขอและไม่ใช้รหัสผ่าน โทเค็นบัญชี หรือสิทธิ์อ่านข้อความ เพื่อน หรือเซิร์ฟเวอร์ของคุณ

ข้อมูลที่โปรแกรมใช้

ข้อมูลที่ Discord ส่งกลับมา

ตอนเชื่อมต่อ แอป Discord ส่งชื่อผู้ใช้ Discord ของคุณกลับมา โปรแกรมใช้ชื่อนี้แสดงในหน้าต่างของโปรแกรมว่าเชื่อมต่อกับบัญชีไหน ไม่บันทึกและไม่ส่งไปที่ใด

การตั้งค่าที่บันทึกในเครื่อง

ค่าที่คุณตั้ง เช่น ข้อความสถานะ ลิงก์ และ Application ID บันทึกไว้ในเครื่องของคุณเท่านั้น:

  • Windows: %APPDATA%\PenguinStatus\config.txt
  • macOS / Linux: ~/.penguin-status/config.json

ลบไฟล์นี้หรือลบโปรแกรมเมื่อไหร่ก็ได้ ข้อมูลจะหายทั้งหมด

โอเวอร์เลย์เวลาบอส (การอ่านหน้าจอ)

  • เมื่อคุณเปิดใช้ "อ่านแมพ" โปรแกรมจับภาพหน้าจอเป็นระยะ เพื่อหาป้ายเวลาบอสบนแมพเกมแล้วอ่านตัวเลขด้วยตัวอ่านตัวหนังสือที่อยู่ในเครื่อง (macOS Vision / Windows OCR)
  • ภาพหน้าจอถูกประมวลผลในหน่วยความจำแล้วทิ้งทันที ไม่บันทึกลงไฟล์ ไม่อัปโหลด และไม่ส่งไปที่ใด
  • สิ่งที่บันทึกในเครื่องมีแค่เวลาเกิดของบอสแต่ละตัวและบอสที่คุณเลือกซ่อน (โฟลเดอร์เดียวกับการตั้งค่าด้านบน)
  • บน macOS ระบบจะขอสิทธิ์ Screen Recording คุณปิดสิทธิ์นี้หรือเอาติ๊ก "อ่านแมพอัตโนมัติ" ออกได้ตลอด

Summary

No personal data collected PenguinCLI (formerly Penguin Status) is a local desktop program that sets your Discord activity and shows a boss-timer overlay. It has no user accounts and no server of its own. It does not send your data to us, and it contains no analytics, tracking, or ads.

How it works

  • The program talks only to the Discord desktop client running on your computer through Discord's local Rich Presence IPC. This traffic never reaches us.
  • It sends Discord only the status text you type, an image URL, optional link buttons, and a start timestamp. Discord then shows this activity on your profile according to your Discord settings.
  • It never asks for or uses your password, account token, or any access to your messages, friends, or servers.

Data the program handles

From Discord: when it connects, the Discord client returns your username. The program shows it in its own window to confirm which account is connected. It is never stored or sent anywhere.

Local settings: your status text, links, and Application ID are saved only on your computer:

  • Windows: %APPDATA%\PenguinStatus\config.txt
  • macOS / Linux: ~/.penguin-status/config.json

You can delete this file or the program at any time.

Boss overlay (screen reading)

  • When you turn on map reading, the program periodically captures the screen to find boss timer labels on the game map and reads them with the text recognizer built into your computer (macOS Vision / Windows OCR).
  • Screenshots are processed in memory and discarded immediately. They are never saved to disk, uploaded, or sent anywhere.
  • Only the boss spawn times and the bosses you choose to hide are stored locally, in the same folder as the settings above.
  • On macOS the system asks for Screen Recording permission. You can revoke it or turn off automatic map reading at any time.

Status image

The status image is https://penguinzgear.com/img/penguin-status.png, hosted on GitHub Pages. Discord loads it through its own systems. We do not receive any information about you or about people who view your profile. GitHub may keep standard access logs under the GitHub Privacy Statement.

Third parties, children, changes, contact

  • How your activity is displayed is governed by the Discord Privacy Policy. You can turn activity sharing off in Discord → Settings → Activity Privacy. You can also press Stop or close the program, and the status disappears immediately.
  • The program collects no data from anyone, including children under 13. Use of Discord is subject to Discord's age requirements.
  • If this policy changes, this page and the date above will be updated.
  • Questions: contact the developer via penguinzgear.com.
